# 대입 합격 현황 입력

학생이 원서별 대입 결과(1단계, 최종단계, 불합격사유, 최초후보순위, 등록여부, 비고)를 입력·제출하고,
관리자가 정렬·필터·엑셀 다운로드·비밀번호 관리를 하는 페이지입니다.

## 구성
- `index.html`: 학생·관리자 화면 (GitHub Pages로 공개)
- `apps-script/Code.gs`: 구글 시트에 붙여 넣는 서버 코드 (데이터는 구글 시트 '학생', '원서' 탭에 저장)

## 운영 메모
- 관리자 비밀번호는 Apps Script의 스크립트 속성 `ADMIN_PW`에만 있습니다. 이 저장소에는 없습니다.
- 학생 처음 비밀번호는 학번(학년+반 2자리+번호 2자리, 예: 30101)입니다.
- 명렬·원서는 관리자 페이지의 ‘명렬·원서 올리기’에서 진학관리 엑셀을 올립니다.
- `Code.gs`를 고치면 Apps Script에서 [배포 관리] > 새 버전으로 다시 배포해야 반영됩니다.
